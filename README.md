# 2026_projects

Três apps pequenos feitos pra prática e portfólio.

## Projetos

| Pasta | Nome | Stack | Descrição |
|---|---|---|---|
| `lume/` | Lume | React + Vite + Tailwind | Hábitos do dia |
| `elo/` | Elo | Angular | Agenda de contatos |
| `pila/` | Pila | Flutter | Despesas e receitas |

## Como rodar

### Lume
```bash
cd lume
npm install
npm run dev
```

### Elo
```bash
cd elo
npm install
npm start
```

### Pila
```bash
cd pila
flutter pub get
flutter run -d chrome
```

Ou, depois de buildar:
```bash
cd pila
flutter build web
# servir a pasta build/web
```
